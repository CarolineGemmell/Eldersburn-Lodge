ELDERSBURN LODGE — VERSION 7 STABLE

FIRST INSTALL
1. Extract this ZIP.
2. Upload these website files to the root of your GitHub repository:
   index.html, styles.css, script.js, site-config.js and image1.png to image10.png.
3. Commit directly to main.
4. Wait for the green GitHub Pages deployment tick.
5. Refresh the live website. Use Ctrl + Shift + R only if the old version remains cached.

NORMAL MANAGEMENT
1. Double-click Eldersburn_Lodge_Manager.html.
2. Select your current site-config.js using the file chooser.
3. Click Load selected file.
4. Change bookings, prices or reviews.
5. Open Save and upload.
6. Download site-config.js.
7. Upload only site-config.js to GitHub.

Do not double-click site-config.js. Windows may block or try to run JavaScript files. The Manager reads it safely through the file chooser.
