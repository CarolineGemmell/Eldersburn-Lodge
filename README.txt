ELDERSBURN LODGE WEBSITE VERSION 3

UPLOAD TO GITHUB
1. Extract this ZIP file
2. Open the Eldersburn-Lodge repository
3. Choose Add file > Upload files
4. Upload every file in this folder
5. Commit directly to the main branch
6. Wait for Pages build and deployment to show a green tick
7. Refresh the live website using Ctrl + F5

OUTLOOK CALENDAR
The published Outlook HTML calendar link is already entered in site-config.js
Add a confirmed booking to the separate Outlook calendar and it will appear there automatically
Use the title Booked and do not put guest names or private information in public calendar entries

IMPORTANT
Some browsers or Microsoft settings may prevent Outlook from appearing inside an iframe
If that happens, visitors can still use the Open Full Calendar link
The manual availability calendar remains in the code as a fallback if you remove the Outlook URL
